# دفتر کلاسی آنلاین آذرمهر ۲.۰

وب‌اپ فارسی مدرسه برای PHP 8.2 و MySQL/MariaDB، طراحی سعید آذرمهر.

امکانات اصلی: ساختار سال، رشته، پایه و کلاس؛ پرونده مرکزی دانش‌آموز؛ ورود فایل اکسل و خروجی سیدا؛ تعریف معلم و تخصیص درس؛ پنج پودمان و شایستگی‌ها؛ حضور‌وغیاب یک‌لمسی؛ نمره با بارم دلخواه؛ فرمول و پیشنهاد نمره؛ گزارش و کارنامه؛ پیام، اعلان، تکلیف، آزمون و فایل پاسخ؛ کارتابل غیبت و انضباط؛ نقش‌های سفارشی و پنل دانش‌آموز.

نسخهٔ قابل نصب در پوشه `outputs` ساخته می‌شود. راهنمای فارسی همراه بسته شامل کلید یک‌بارمصرف نصب است. بسته هیچ حساب یا رمز پیش‌فرض و هیچ تنظیم پایگاه داده‌ای ندارد.

## ساخت محلی

    npm ci
    npm run typecheck
    npm run build

رابط در `app` و `lib`، سرور PHP در `host` و مهاجرت‌های پایگاه داده در `host/private/migrations.php` قرار دارند. حالت توسعه داده نمونه دارد؛ ساخت نهایی از `school-api.php` و ذخیره‌سازی مرکزی استفاده می‌کند.

## امنیت و داده

مجوزها در سرور دوباره بررسی می‌شوند. نشست امن، CSRF، کپچا، محدودیت تلاش ورود، اعتبارسنجی فایل، فایل خصوصی و ثبت تاریخچه تغییرات فعال‌اند. مدیر و معاون امکان مشاهده نمره دارند، اما تغییر نمره تنها برای معلم تخصیص‌یافته همان درس پذیرفته می‌شود.

ارسال واقعی پیامک تا ثبت پنل سرویس غیرفعال است. مشخصات عمومی سرویس و مخاطبان قابل ثبت‌اند؛ کلید سرویس در داده مدرسه ذخیره نمی‌شود.
